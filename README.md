# Critical Reading Worksheet

A single-file, interactive worksheet for structured critical appraisal of
health services & health policy research manuscripts.

- Fill it out in the browser (autosaves locally, keeps a library of multiple papers).
- Paste a DOI to auto-fill the citation via CrossRef.
- Export to **RIS** (worksheet → Notes, categorical answers → tags) to attach to a
  reference in Paperpile, Zotero, or Mendeley — or to **Markdown** / **JSON**.
- Import a JSON export to resume on any browser or machine.

The entire tool is `index.html` — no build step, no dependencies, no server.

## Hosting

Served as a static page (e.g., GitHub Pages). Nothing to configure.
